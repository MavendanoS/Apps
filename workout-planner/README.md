# 💪 Mi Entrenamiento en Casa

Una aplicación web progresiva para planificar y seguir tus entrenamientos en casa desde tu celular.

## 🚀 Características

- **Biblioteca de Ejercicios**: 18 ejercicios predefinidos categorizados en:
  - Cardio (saltos, burpees, etc.)
  - Fuerza (flexiones, sentadillas, etc.)
  - Flexibilidad (estiramientos, yoga)

- **Rutinas Personalizadas**: Crea tus propias rutinas combinando los ejercicios que prefieras

- **Planificador Diario**: Selecciona una rutina para tu entrenamiento del día

- **Seguimiento de Progreso**: Marca ejercicios como completados y ve tus estadísticas

- **Almacenamiento Local**: Todos tus datos se guardan en tu navegador

- **Diseño Responsivo**: Optimizado para dispositivos móviles

## 📱 Cómo Usar

### Abrir la App

1. Abre el archivo `index.html` en tu navegador móvil
2. Para mejor experiencia, añádela a tu pantalla de inicio:
   - **iOS**: Safari → Compartir → Añadir a pantalla de inicio
   - **Android**: Chrome → Menú → Añadir a pantalla de inicio

### Crear una Rutina

1. Ve a la pestaña **"Rutinas"**
2. Presiona el botón **"+ Nueva Rutina"**
3. Ingresa un nombre para tu rutina
4. Selecciona los ejercicios que quieres incluir
5. Presiona **"Guardar Rutina"**

### Planificar tu Entrenamiento del Día

1. Ve a la pestaña **"Hoy"**
2. Presiona **"Seleccionar Rutina"**
3. Elige la rutina que quieres hacer hoy
4. ¡Comienza tu entrenamiento!

### Durante el Entrenamiento

- Cada ejercicio muestra:
  - Número de series
  - Repeticiones por serie
  - Tiempo de descanso
- Presiona **"Marcar como Completado"** al terminar cada ejercicio
- Las estadísticas se actualizan automáticamente

### Explorar Ejercicios

1. Ve a la pestaña **"Ejercicios"**
2. Filtra por categoría (Todos, Cardio, Fuerza, Flexibilidad)
3. Revisa los detalles de cada ejercicio

## 💡 Consejos

- **Calentamiento**: Empieza siempre con ejercicios de cardio ligero
- **Descanso**: Respeta los tiempos de descanso entre series
- **Progresión**: Aumenta gradualmente la intensidad
- **Constancia**: Crea rutinas variadas para mantener la motivación
- **Hidratación**: Mantén agua cerca durante tu entrenamiento

## 🔧 Instalación Local

Para usar la app localmente:

1. Clona o descarga este repositorio
2. Abre `index.html` en tu navegador
3. No requiere instalación de dependencias ni servidor

- Todos los datos se almacenan localmente en tu navegador
- No se envía información a ningún servidor
- Tus datos permanecen privados y bajo tu control
- Para borrar datos: limpia el almacenamiento local de tu navegador
